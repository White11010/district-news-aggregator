Разработать лендинг с списком новостей для отдела маркетинга
описание
Разработать техническую страницу для SMM-команды на GitHub Pages, позволяющую быстро просматривать новости по районам Санкт-Петербурга за последние 2–3 дня для отбора информации при оформлении постов в сообществе/канале «Макс». Визуал не имеет значения, верстка тоже — должно быть понятно для просмотра и копипаста информации.

Требования:

Отображение новостей с разбивкой по районам.
По умолчанию загружаются новости за последние 2 дня (сегодня + вчера).
Возможность выбора периода: от 1 до 3 дней (включая текущий день).
Параметры запроса к API:
start_date — текущая дата (передаётся автоматически).
period — количество дней (1, 2 или 3).
count — 300 (максимальное количество новостей за запрос).
page — номер страницы (для пагинации).
Пагинация
100 новостей на страницу (возможна настройка в процессе тестирования).
Реализовать стандартные элементы пагинации: номера страниц, «Вперёд»/«Назад».
Метод получения новостей:
[https://yazzh.gate.petersburg.ru/news/districts_period/?start_date=2026-08-04&period=2&page=1&count=300](https://yazzh.gate.petersburg.ru/news/districts_period/?start_date=2026-08-04&period=2&page=1&count=300)
(для указаний района используется параметр district)

Набор обрабатываемых полей:

datetime_start (дата новости, в формате dd-mm)
name (заголовок)
description (описание). Ограничить длину выводимого текста до 500 символов с возможностью развернуть полный текст.
media_files (достаточно одного, первого изображения. При отсутствии, заглушка не требуется, не выводим изображение, на усмотрение)
Фильтр по районам:

По умолчанию — выводятся новости всех районов.
Фильтр позволяет выбрать один конкретный район.
Кнопка «Сбросить фильтр» — возвращает отображение всех районов.
Множественный выбор не требуется.
Метод получения списка районов:
[https://yazzh.gate.petersburg.ru/news/districts/](https://yazzh.gate.petersburg.ru/news/districts/)
